# Personal Portfolio

🚧 **Work in Progress**

My personal portfolio website, currently under active development.

The goal of the website is to present my background, experience, technical skills and personal projects in a way that reflects both my interest in software development and software testing.

![Portfolio preview](./screenshot.png)

## Current status

The website is still under development. The current version contains the basic layout and sections for:

- About me
- Skills
- Experience
- Education
- Projects
- Contact

More content, functionality and visual improvements will be added as development continues.

## Tech Stack

- JavaScript
- React
- Node.js

## Why I'm building this

I'm building this project as both a personal portfolio and a way to practice frontend development, UI design and project structure.

I also want the project to demonstrate how I approach developing something from an initial idea into a finished product.
